# AI and ML System

The AI layer is intentionally narrow and explainable.

## Structured algorithms

- skill scoring using weighted evidence
- gap calculation against target role requirements
- priority scoring based on gap size, importance, and recency
- recommendation selection from role-based evidence

## LLM usage

- resume parsing and extraction of unstructured evidence
- explaining skill gaps in natural language
- summarizing long-term candidate progress
- generating polished recommendation narratives

## Guardrails

- no fabricated candidate information
- no AI-only decisions when deterministic logic is sufficient
- output must be grounded in stored evidence and role metadata
